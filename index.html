01 / AI

AI로 만드는 프로필 사진

사진관에 가지 않아도 한 장의 촬영으로 프로필 사진을 만드는 웹 서비스입니다. 기술 선택마다 왜 그렇게 판단했는지를 남겼습니다.

졸업작품 / 개인Python, Flask
OpenCV
DeepLabV3+

기획, 개발, 전시회 발표까지 단독 수행

웹캠 촬영→얼굴 검출→3:4 크롭→인물 분할 (DeepLabV3+)→배경색, 밝기, 필터→저장, 이메일 전송

직접 써 보기

졸업작품 결과 이미지와 실제 보정 공식으로 재현한 웹 데모
배경 교체

인물 영역을 분리한 뒤 고른 색을 배경에 적용합니다. 서비스에서도 컬러 팔레트를 누르면 바로 바뀌도록 만들었습니다.

밝기와 필터
0
v = clip(v + level*4, 0, 255)

HSV 색공간에서 명도(V)만 바꿔 색상과 채도는 그대로 둡니다.

진단

색상 기준 배경 제거의 한계

처음에는 구현이 간단한 색상 기반 방식을 썼습니다. 그런데 촬영 환경마다 조명과 배경색이 달라 머리카락이나 옷까지 함께 지워졌습니다. 색상으로는 사람과 배경을 구분할 수 없다고 판단했습니다.

선택

DeepLabV3+ 기반 인물 분할로 전환

픽셀 단위로 사람 영역을 분리하는 세그멘테이션 모델로 바꾸고, 경계 검출, 마스크 확장, 블렌딩으로 후처리했습니다. 머리 경계와 옷 경계 같은 판정 기준은 결과를 보며 직접 세우고 조정했습니다. 방법을 검토할 때는 ChatGPT를 참고했고, 막히는 부분은 교수님과 선배를 찾아가 여쭤봤습니다.

트레이드오프

알고리즘 대신 입력을 통제

측면이나 어두운 사진에서는 얼굴 검출이 자주 실패했습니다. 알고리즘을 무리하게 고도화하기보다 정면과 밝은 환경 촬영을 안내하고, 실패하면 재촬영을 유도하는 쪽을 택했습니다.

세부 판단

색이 틀어지지 않게 보정

밝기는 HSV 색공간에서 명도 채널만 조정해 색상과 채도를 지켰습니다. 필터가 얼굴 톤까지 바꾸던 문제는 인물과 배경 영역을 나눠 따로 보정해 해결했습니다.

한계

남은 과제를 숨기지 않기

가는 머리카락 끝의 경계와, 원본 조명과 새 배경색의 부조화는 완전히 해결하지 못했습니다. 보고서에 한계로 명시하고 경계 블렌딩과 조명 보정을 개선 과제로 남겼습니다.

60 → 88

같은 100건을 같은 기준(윤곽 손실, 배경 잔여)으로 재검증한 통과 건수

졸업작품 전시회에서 직접 시연했고, 학생들이 결과물을 꽤 마음에 들어 해 뿌듯했습니다.

신중한 해석

날씨만의 효과로 단정하지 않기

같은 기간에 계절과 요일 같은 요인도 함께 작용했기 때문에, 결과를 발표할 때 이 차이를 날씨 하나의 효과로 단정하지 않았습니다.
